# changxeoksong.github.io

Personal research portfolio — https://changxeoksong.github.io

Static HTML/CSS/JS, no build step.

- `index.html` / `ko.html` — home (EN / KO)
- `projects/<name>.html` / `projects/<name>.ko.html` — project pages (EN / KO)
- `assets/style.css` — design tokens, layout, light/dark themes
- `assets/site.js` — theme toggle, active-section nav, copy/selection deterrents
- `assets/img/` — figures (WebP/SVG, original aspect ratio) · `assets/papers/` — paper PDFs
